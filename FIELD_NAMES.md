# Field Name Contract

The frontend stores user data in one flat `userData` object. Every key below is a supported form field key. Calibrated `frontend/public/fieldMap.json` entries must use these names exactly.

Checkbox fields use the value `X`; the PDF filler draws the literal text `X`.
